## Описание программы (кратко)
GitHub User Finder — десктопное приложение на Python с графическим интерфейсом (Tkinter), позволяющее искать пользователей GitHub по логину через официальный API и сохранять их в список избранного. Программа даёт возможность быстро находить и систематизировать учётные записи разработчиков для дальнейшего использования.


### Возможности (что программа умеет делать)
* **Поиск пользователей GitHub** по логину с использованием официального API (`api.github.com`).
* **Отображение до 15 первых результатов** поиска в интерактивном списке.
* **Добавление пользователей в избранное** из результатов поиска.
* **Сохранение списка избранных пользователей** между запусками программы в JSON‑файле (`favorites.json`).
* **Визуализация избранного** в отдельном списке внутри интерфейса.
* **Проверка корректности ввода** (предупреждение, если поле поиска пустое).
* **Обработка ошибок**:
    * сетевых проблем (отсутствие подключения, сбои);
    * ошибок API (некорректный ответ сервера);
    * дублирования записей в избранном.
* **Информирование пользователя** через всплывающие сообщения о статусе операций (успех, предупреждение, ошибка).

## Инструкция по запуску

### Требования для запуска программы
* Python 3.6 или выше.
* Установленные библиотеки:
    * `tkinter` (встроен в стандартную поставку Python, GUI‑фреймворк);
    * `requests` (для выполнения HTTP‑запросов к GitHub API);
    * `json` (для работы с JSON‑файлами);
    * `os` (для проверки существования файла избранного).
